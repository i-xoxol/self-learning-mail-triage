# Contributing

Use fictional fixtures and reserved example domains. Do not commit caches, profiles, learned rules, real contacts, message contents, exports, or machine-local configuration.

Install `requirements.txt`, run the unittest suite, `scripts/check_mcp.py`, and `scripts/audit_public_source.py`. Tests must work offline without an email account. Explain the problem, resulting behavior, relevant verification, and limits in a pull request.

Preserve unsent drafting, complete reviewed plans, delegated `/me` access, confirmed registry changes, mailbox-scoped cases, explicit review for non-style rules, and opt-in style automation. Sending or deleting mail would require a separate design and is outside the current project.

Keep documentation accurate about stored data, heuristic matching/redaction, host approval responsibilities, and the distinction between preference learning and model training.
